# Sistem Informasi Perpustakaan 

Project Praktikum Pemrograman Web (Modul 5) - Sistem manajemen perpustakaan sederhana (Database & Function)

## Fitur Aplikasi
- **Dashboard Modul Member:** CRUD (Create, Read, Update, Delete) data anggota.
- **Dashboard Modul Buku:** CRUD data inventaris buku perpustakaan.
- **Dashboard Modul Peminjaman:** Manajemen transaksi peminjaman buku 

## Tools yang Digunakan
- **Backend:** PHP Native
- **Database:** MariaDB / MySQL
- **Frontend Framework:** Tailwind CSS (CDN)
